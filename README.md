# Карта загроз — Дніпропетровщина

Відкритий застосунок-аналог «Віражу»: мапа Дніпропетровської області з цілями
(БпЛА, реактивні цілі, КР, БР), що розпізнаються з публічних Telegram-каналів
спостерігачів, плюс офіційний статус повітряної тривоги.

> ⚠️ **Дисклеймер.** Застосунок не є офіційною системою оповіщення. Дані мають
> затримку і можуть бути неповними або неточними. Офіційне джерело —
> сигнал «Повітряна тривога» та місцева влада.

## Основний режим: Python + HTML (уся логика в Python)

```bash
pip install telethon      # для режиму Telegram API
python server.py          # перший запуск створить config.json
# -> впиши свій api_id / api_hash (https://my.telegram.org) у config.json
# -> python server.py     # знову
# Карта: http://127.0.0.1:8080
```

- **server.py** — уся логика на Python: читання Telegram (Telethon з твоїм
  api_id/api_hash; фолбэк — web-превью `t.me/s/<канал>`), парсинг, треки,
  `/state.json` без кешу.
- **static/index.html** — суто векторна карта без зовнішніх підкладок: детальний
  контур області (9793 точки), ріки (Дніпро, Інгулець, Самара...), водойми,
  шляхи/залізниці, міста; Leaflet з 3 дзеркал CDN або канвас-фолбэк.
- Позначення: **жовтий «+»** — без прямої загрози містам, **червоний «+»** —
  загроза містам (наближення/над вами або ближе 45 км до обласних міст),
  **сірий «+»** — ціль пропала, **червоний «?»** — невідома ціль.
- Ціль зникає з карти, якщо не фіксується **5 хвилин**.
- Кордон області червоний лише під час тривоги.
- `data/dictionaries.json`, `data/settlements.json` — словники; правляться без
  перезапуску логики (перезапусти сервер).

## Стек (легасі: Android-застосунок)

- **Java** (Android, без сторонніх залежностей — лише `org.json` з платформи)

## Як працює розпізнавання

1. **Нормалізація**: нижній регістр, ё→е, ы→и, апострофи, латинські
   гомогліфи в кириличних словах.
2. **Фільтр шуму**: донати (номери карток), «тихої ночі», метаповідомлення.
3. **Пост-тривоги** (🔴/🟢) — окремий вид запису, дзеркало офіційного статусу.
4. **Словниковий розбір** за коренями слів + нечітке зіставлення
   (Дамерау-Левенштейн ≤1): тип цілі, кількість (`1х`, `+1`, «пара»),
   напрямок, висота, статус.
5. **Геокодування**: довідник ~82 обʼєктів — міста, мікрорайони Дніпра, села
   та райони (Дніпровський, Камʼянський, Криворізький, Нікопольський,
   Павлоградський, Самарівський, Синельниківський + старі райцентри).
   Розпізнаються відмінки («кривого рогу», «никополю»), сленг («авик», «птх»,
   «синюха», «юмз», «дзержинск»), префіксні збіги та одруківки
   (Дамерау-Левенштейн ≤1). Напрямки/статуси («південь», «над вами») не
   плутаються з назвами місць. Якщо є і НП, і район — район відкидається.
6. **Склейка треків**: відповіді на повідомлення в Telegram прив'язуються
   до треку оригіналу (`reply_to`); «той самий турист» → попередній трек канала,
   `+1`/«новий» → новий трек. Напів-повідомлення без НП («Без фіксації», «Вылез»,
   «курим») теж оновлюють статус останнього треку канала.
7. **Позиція цілі**: якщо ціль летить на велике місто (не «над вами» і не
   «пропал»), маркер ставиться за ~15 км від міста — за відомим курсом,
   а без курсу — на стабільному випадковому азимуті. Загроза видна, але не
   «БпЛА над самим містом».
8. Опитування Telethon кожні 5 с (авторизований юзер), веб-фолбек — 15 с.
9. **Фолбек**: нічого не розпізналось у типі → «Ціль» (сірий маркер).
   Локації немає → запис лише у стрічці.

Статуси: `Зафіксовано`, `Курс`, `Транзит`, `Наближення`, `Над вами`,
`Циркулює`, `Пропав`, `Знову виявлений`, `Пішов`, `Без загроз`, `Відбій`.

## Запуск без Gradle (Termux-сервер)

```bash
pip install nothing  # тільки стандартна бібліотека
python termux_server.py
# Карта: http://127.0.0.1:8080 (лише локально)
```

Сервер читає ті самі словники, що і Android-застосунок, опитує Telegram (20 с)
та офіційну тривогу (60 с), віддає `state.json` без кешування.

## Запуск index.html подвійним кліком

`index.html` працює з `file://` і **реально тягне дані з джерел**:
- словники — `data-dict.js`, границя — `dnipro-geo.js` (класичні `<script>`, XHR не потрібен);
- опитування Telegram і тривоги йде в браузері (`pipeline.js`):
  спочатку прямий запит, далі CORS-проксі (allorigins → corsproxy);
- парсер у браузері читає ті самі словники, фолбек «ціль» працює так само;
- Leaflet з 3 дзеркал CDN (unpkg → jsdelivr → cdnjs), якщо недоступний —
  резервна канвас-карта без CDN (панорама, зум, «+»);
- у нижньому рядку видно статус джерел: «джерела: 3/4 працюють».

## Збірка

1. Відкрийте корінь проєкту в **Android Studio** (вона підтягне сумісний Gradle).
2. `Run ▶` на пристрої/емуляторі з мін. API 24 (Android 7.0).
3. Тести парсера: `./gradlew :app:testDebugUnitTest` (або через IDE).
4. Збірка APK лише Termux — скрипт `termux_build.py`.

## Позначення на мапі

- **«+» жовтий** — ціль без прямої загрози великим містам;
- **«+» червоний** — наближення/над вами або ціль ближ ніж 45 км до
  Дніпра, Кривого Рогу, Нікополя, Кам'янського чи Павлограда;
- **«+» сірий** — пропав (без фіксації).

## Обмеження та відомі спрощення

- Координати НП приблизні (±1 км) — ціль позначається точкою населеного пункту,
  а не точною позицією; точність джерела — «село/район».
- Опитування йде лише коли застосунок відкритий (Android обмежує фонову мережу);
  фоновий режим з Foreground Service — наступний крок.
- Сленг-словник потребує постійного поповнення — це конфіг, а не код.
- «Реактив» не розрізняє КР і реактивний БпЛА, якщо канал не уточнив.

## Дорожня карта

1. Фоновий трекінг (Foreground Service) + звукове сповіщення про тривогу.
2. Офіційний API `alerts.in.ua` з ключем (замість ubilling) + рівні районів.
3. Історія за добу, фільтри за типом цілі, шар тривог районів.
4. Накопичення словника сленгу з розбору невпізнаних рядків (админ-режим).
