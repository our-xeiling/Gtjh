# Карта загроз — Дніпропетровщина

Відкритий застосунок-аналог «Віражу»: мапа Дніпропетровської області з цілями
(БпЛА, реактивні цілі, КР, БР), що розпізнаються з публічних Telegram-каналів
спостерігачів, плюс офіційний статус повітряної тривоги.

> ⚠️ **Дисклеймер.** Застосунок не є офіційною системою оповіщення. Дані мають
> затримку і можуть бути неповними або неточними. Офіційне джерело —
> сигнал «Повітряна тривога» та місцева влада.

## Стек

- **Java** (Android, без сторонніх залежностей — лише `org.json` з платформи)
- **JSON** — словники, довідник населених пунктів, обмін WebView ↔ Java
- **HTML/Leaflet** у WebView — карта, темно/світла теми, українська мова

## Як працює розпізнавання

1. **Нормалізація**: нижній регістр, ё→е, ы→и, апострофи, латинські
   гомогліфи в кириличних словах.
2. **Фільтр шуму**: донати (номери карток), «тихої ночі», метаповідомлення.
3. **Пост-тривоги** (🔴/🟢) — окремий вид запису, дзеркало офіційного статусу.
4. **Словниковий розбір** за коренями слів + нечітке зіставлення
   (Дамерау-Левенштейн ≤1): тип цілі, кількість (`1х`, `+1`, «пара»),
   напрямок, висота, статус.
5. **Геокодування**: довідник населених пунктів + сленг-аліаси
   (Авик→Авіаторське, ПТХ→Підгороднє, ЮМЗ тощо), декілька локацій у рядку = траєкторія.
6. **Склейка треків**: «той самий турист» → попередній трек канала,
   `+1`/«новий» → новий трек, «Відбій» → закриття треків канала.
7. **Фолбек**: нічого не розпізналось у типі → «Ціль» (сірий маркер).
   Локації немає → запис лише у стрічці.

Статуси: `Зафіксовано`, `Курс`, `Транзит`, `Наближення`, `Над вами`,
`Циркулює`, `Пропав`, `Знову виявлений`, `Пішов`, `Без загроз`, `Відбій`.

## Запуск без Gradle (Termux-сервер)

```bash
pip install nothing  # тільки стандартна бібліотека
python termux_server.py
# Карта: http://127.0.0.1:8080 (лише локально)
```

Сервер читає ті самі словники, що і Android-застосунок, опитує Telegram (20 с)
та офіційну тривогу (60 с), віддає `state.json` без кешування.

## Запуск index.html подвійним кліком

`index.html` працює з `file://`:
- границя області — `dnipro-geo.js` (класичний `<script>`, 9793 точок, OSM/geoBoundaries);
- Leaflet тягнеться з 3 дзеркал CDN (unpkg → jsdelivr → cdnjs);
- якщо Leaflet недоступний — резервна канвас-карта без CDN (панорама, зум, «+»).

## Збірка

1. Відкрийте корінь проєкту в **Android Studio** (вона підтягне сумісний Gradle).
2. `Run ▶` на пристрої/емуляторі з мін. API 24 (Android 7.0).
3. Тести парсера: `./gradlew :app:testDebugUnitTest` (або через IDE).
4. Збірка APK лише Termux — скрипт `termux_build.py`.

## Позначення на мапі

- **«+» жовтий** — ціль без прямої загрози великим містам;
- **«+» червоний** — наближення/над вами або ціль ближ ніж 45 км до
  Дніпра, Кривого Рогу, Нікополя, Кам'янського чи Павлограда;
- **«+» сірий** — пропав (без фіксації).

## Обмеження та відомі спрощення

- Координати НП приблизні (±1 км) — ціль позначається точкою населеного пункту,
  а не точною позицією; точність джерела — «село/район».
- Опитування йде лише коли застосунок відкритий (Android обмежує фонову мережу);
  фоновий режим з Foreground Service — наступний крок.
- Сленг-словник потребує постійного поповнення — це конфіг, а не код.
- «Реактив» не розрізняє КР і реактивний БпЛА, якщо канал не уточнив.

## Дорожня карта

1. Фоновий трекінг (Foreground Service) + звукове сповіщення про тривогу.
2. Офіційний API `alerts.in.ua` з ключем (замість ubilling) + рівні районів.
3. Історія за добу, фільтри за типом цілі, шар тривог районів.
4. Накопичення словника сленгу з розбору невпізнаних рядків (админ-режим).
